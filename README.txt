发布说明

请将本文件夹中的所有文件和文件夹一起上传到静态网站托管平台。
不要只上传 index.html；assets 文件夹中的图片和视频是网页的一部分。

GitHub Pages：
1. 新建一个 GitHub 仓库。
2. 上传本文件夹的全部内容，确保 index.html 位于仓库最外层。
3. 在仓库 Settings → Pages 中，将 Source 设为 Deploy from a branch，分支选择 main / root。
4. 保存后等待 GitHub 生成网站链接。

注意：视频文件较大。如果 GitHub 拒绝上传，请告诉 Codex，我会为网站生成更轻量的视频版本或改用视频托管链接。
