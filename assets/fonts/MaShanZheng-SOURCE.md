# Ma Shan Zheng: desktop character supplement

- Source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
- Copyright 2018 The Ma Shan Zheng Project Authors
- License: SIL Open Font License 1.1; see OFL-MaShanZheng.txt.
- Font weight: 400.
- The WOFF2 subset contains U+517D (兽), using the original glyph and naming metadata.
- CSS unicode-range applies this clearer brush glyph wherever the desktop calligraphy font is used. The page text remains 兽.
