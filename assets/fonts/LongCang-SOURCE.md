# Long Cang desktop title font

- Official distribution: https://github.com/google/fonts/tree/main/ofl/longcang
- Source TTF: https://raw.githubusercontent.com/google/fonts/main/ofl/longcang/LongCang-Regular.ttf
- Official description: https://github.com/google/fonts/blob/main/ofl/longcang/DESCRIPTION.en_us.html
- Original design is based on Chen Xiaomin’s handwritten script.
- Weight: 400. CSS alias: `Desktop Brush`.
- Website file: `LongCang-Desktop.subset.woff2`.
- License: SIL Open Font License 1.1, included unchanged in `OFL-LongCang.txt`.

Only characters used by the desktop website are included for efficient web delivery. Font outlines, original naming, copyright and license metadata are retained. All Chinese characters in the desktop document are covered. Small controls continue to use LXGW WenKai; the artist signature uses its existing separate font.
