# Website typography font sources

## LXGW WenKai Medium

- Official repository: https://github.com/lxgw/LxgwWenKai
- Original TTF: https://raw.githubusercontent.com/lxgw/LxgwWenKai/main/fonts/TTF/LXGWWenKai-Medium.ttf
- Original file version: `Version 1.522; March 17, 2026`.
- Original family/full name: `LXGW WenKai Medium`.
- Weight: `500`; style: normal.
- Website CSS alias: `Mobile WenKai`.
- Web-delivery subset: `LXGWWenKai-Medium.mobile.subset.woff2`.
- Independent desktop web-delivery subset: `LXGWWenKai-Medium.desktop.subset.woff2`; suggested CSS alias: `Desktop WenKai`.
- License: SIL Open Font License 1.1; see the accompanying, unmodified `LXGWWenKai-OFL.txt`.
- License source: https://raw.githubusercontent.com/lxgw/LxgwWenKai/main/OFL.txt

The supplied WOFF2 is a web-only subset of the official TTF. It retains the original font naming and license metadata. No outlines have been changed. The upstream license includes additional permission to retain the reserved font names in subsets and format conversions made solely for web font delivery.

The character subset covers the mobile HTML, embedded artwork metadata, JavaScript UI labels, and the additional editorial titles supplied for this site. The WOFF2 is distributed under the same OFL 1.1 license as the source. The full desktop-installable TTF is not distributed in this website repository.

The separate desktop subset covers the desktop HTML, the mobile HTML and JavaScript for shared vocabulary, and the additional desktop editorial copy. It uses the same official Medium source and accompanying license. Building the desktop subset does not modify the mobile font or mobile pages.

## Zhi Mang Xing footer signature

- Official distribution: https://github.com/google/fonts/tree/main/ofl/zhimangxing
- Original TTF: https://raw.githubusercontent.com/google/fonts/main/ofl/zhimangxing/ZhiMangXing-Regular.ttf
- Family: `Zhi Mang Xing`; weight: `400`; style: normal.
- Signature web subset: `ZhiMangXing-Signature.subset.woff2`, containing `王淳` only.
- License: SIL Open Font License 1.1; see the accompanying `OFL-ZhiMangXing.txt`.

Both signature characters have verified native glyphs. The source font's outlines and font naming/license records are retained.
